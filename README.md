# Oi, eu sou o Nic

Desenvolvedor full-stack em formação, com foco em aplicações web, back-end com C#/.NET e integração com bancos de dados. Tenho experiência em projetos usando ASP.NET Core MVC, Entity Framework, SQL Server, PostgreSQL e JasperReports, além de atuar no front-end com React, TypeScript, JavaScript, SCSS e HTML5.

## Sobre mim

- Gosto de desenvolver soluções completas, conectando interface, regra de negócio e banco de dados
- Minha base principal no back-end é C# com .NET, ASP.NET Core MVC e Entity Framework
- Tenho prática com SQL Server, PostgreSQL e criação de relatórios com JasperReports
- No front-end, trabalho com React, TypeScript, JavaScript, SCSS, HTML5 e jQuery
- Também já desenvolvi projetos antigos com Python e Java
